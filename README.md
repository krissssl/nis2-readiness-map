# NIS2 Sagatavotības Karte: исходный код проекта

Всё, что построено в проекте: сайт, бесплатная проверка, рабочий инструмент, презентация, Excel-трекер и документация. Язык интерфейса: латышский.

## Структура

| Папка | Что внутри | Как открыть |
|---|---|---|
| `web/hub/index.html` | Многостраничный сайт: Sākums, Regulējums, Produkts, Metodoloģija, Pārbaude, Kontakti | Двойной клик, работает сам по себе |
| `web/landing/index.html` | Одностраничный лендинг | Двойной клик |
| `web/free-check/index.html` | Бесплатный мастер применимости (без базы данных, всё в браузере) | Двойной клик |
| `web/tool/index.html` | Рабочий инструмент, несколько проектов (содержит данные-пример QUANT) | Нужна среда claude.ai, см. ниже |
| `web/tool-client-copy/index.html` | То же, но один проект и без списка проектов (копия на клиента) | Нужна среда claude.ai |
| `deck/` | `build.js` собирает презентацию (22 слайда), готовый `.pptx` рядом | `npm install && node build.js` |
| `tracker/` | Первый Excel-трекер (`.xlsx`). Скрипт его сборки не сохранился | Excel |
| `build-helpers/` | Общий CSS стиля и модули (отчёт/импорт, нормативная база), скрипты накатывания правок. История сборки, для работы не нужны: итоговые файлы уже содержат весь код | Только для справки |
| `docs/` | Анализ закона, методология, спецификации (см. «Чувствительное») | Любой редактор |

Каждая страница это один самодостаточный HTML-файл: CSS в `<style>`, JS в `<script>`. Шрифты (Space Grotesk, IBM Plex Mono) подгружаются с Google Fonts, без интернета сработает запасной шрифт.

## Рабочий инструмент: что важно знать

`web/tool` использует возможности среды claude.ai (`window.claude.use(...)`): `db` (общая база), `user`, `sample` (AI) и `downloads` (сохранение файлов). **Вне этой среды** их нет: инструмент открывается в «Lokāls skats», данные не сохраняются, кнопки AI и скачивания не работают. Чтобы сделать из него самостоятельное приложение, нужен слой хранения (см. «Путь к приложению»).

Главные места в коде `web/tool/index.html` (искать по имени):
- `DOC`, `pdoc()`, `pcol()`: все пути данных проекта (`projects/{id}/...`);
- `dbGet`, `dbSet`, `dbUpdate`, `dbWrite`, `SaveState`: слой хранения с видимым статусом сохранения;
- `esc()`: экранирование всего, что вставляется в HTML;
- `CONTROLS`, `CATEGORIES`: список контролей и 10 категорий;
- `evState`, `evidenceStats`: модель доказательств (заполнено / подтверждено / не подтверждено);
- `generateReadinessStatement`: текст готовности только из подтверждённых данных;
- `collectProjectData`, `datiSanitize`, `buildReportHtml`: экспорт, импорт с проверкой, отчёт;
- `NORMS`, `NORM_OPEN`: нормативная база и открытые вопросы;
- `SINGLE_PROJECT_MODE`: режим «один проект» (в `tool-client-copy` включён).

## Презентация

```
cd deck
npm install
node build.js
```
`build.js` в конце вызывает `apply_theme.js` из среды Claude (`/mnt/skills/public/pptx/scripts/`). Вне неё этот шаг можно удалить: презентация соберётся и без него (потеряется только палитра темы в PowerPoint). Шрифт презентации Arial.

## Путь к настоящему приложению

1. Заменить вызовы `window.claude.use('db')` слоем хранения на реальной базе (одна функция чтения и записи, остальной код трогать не придётся).
2. Добавить вход и роли (admin / consultant / client / viewer) и серверные правила доступа. Сейчас защита клиентов держится только на том, что у каждого своя копия.
3. Вынести `<style>` и `<script>` в отдельные файлы и разбить JS на модули.
4. Написать тесты для расчётов (проценты, приоритеты, уровни готовности) и импорта.
5. Решить конфликты одновременного редактирования (сейчас «побеждает последняя запись»).
6. Заменить `confirm()` в кнопках удаления встроенным подтверждением (окно может блокироваться в песочнице).
7. Расширить список контролей (сейчас 17 из ~50) и сверить с постановлением Nr. 397 через юриста.

## Известные ограничения

- Нет авторизации и ролей. «Vadības skats» это режим показа, а не защита доступа.
- Два человека могут перезаписать друг друга; повторная отправка после ошибки может перезаписать более новое значение старым.
- Постановление Nr. 397: не проверено, менялось ли оно после июньских поправок 2026 года. Ссылки на акты ЕС собраны по стандартным идентификаторам и не открывались.
- Это инструмент самооценки, а не юридическое заключение, аудит или пентест.

## Чувствительное: проверь перед пересылкой третьим лицам

- `docs/internal-quant/` содержит анализ конкретной компании (QUANT), `docs/internal-business/` внутренние планы и расчёт цен.
- В `web/tool/index.html` зашиты данные-пример QUANT (`ensureQuantSeed`, `seedQuantApplicabilityIfNeeded`). Перед передачей кому-либо удали эти функции и вызовы.
- В `web/hub`, презентации и лендинге указаны контакты quantrum.lv. Проверь, что они должны там быть.
- Использование QUANT как публичного кейса требует согласия руководства компании.
